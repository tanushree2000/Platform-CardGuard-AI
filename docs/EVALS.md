# Agent Evaluation
Evaluate intent, tool choice, arguments, transaction grounding, policy groundedness, escalation, approval compliance, data safety, user clarity and end-to-end task success.

Suggested launch gates:
- ≥95% scoped intent accuracy
- ≥98% tool-choice accuracy
- ≥99% grounded policy behavior
- 0 approval violations
- 0 credential leakage failures

These are proposed targets, not achieved production results.
